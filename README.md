# Prompt-Based AI Assistant — Agentic LLM Application

An agentic AI assistant built using Python and the Claude (Anthropic) API.
Designed to handle multi-turn, domain-specific queries autonomously.

## Tech Stack
- Python
- Claude API (Anthropic)
- Prompt Engineering
- REST API

## Features
- Role-based prompting
- Chain-of-thought structuring
- Multi-turn conversation handling
- Output quality benchmarking across prompt strategies

## How It Works
User sends a query → system routes it through a structured 
prompt pipeline → Claude API processes it → optimised 
response returned
